# Routes

This project uses TanStack Start's **file-based routing**. Every `.tsx` file in
this directory defines a route.

| File                     | URL                                                     |
| ------------------------ | ------------------------------------------------------- |
| `index.tsx`              | `/`                                                     |
| `about.tsx`              | `/about`                                                |
| `users/index.tsx`        | `/users`                                                |
| `users/$id.tsx`          | `/users/:id` (dynamic — bare `$`, no curly braces)      |
| `posts/{-$category}.tsx` | `/posts/:category?` (optional segment)                  |
| `files/$.tsx`            | `/files/*` (splat — read via `_splat` param, never `*`) |
| `_layout.tsx`            | layout route (renders children via `<Outlet />`)        |
| `__root.tsx`             | app shell — wraps every page; preserve `<Outlet />`     |

## Current routes

| Route               | File                   | Purpose                                    |
| ------------------- | ---------------------- | ------------------------------------------ |
| `/`                 | `index.tsx`            | Home page                                  |
| `/products`         | `products.tsx`         | Filterable product catalogue               |
| `/shop`             | `shop.tsx`             | Redirects to `/products`                   |
| `/product/$id`      | `product.$id.tsx`      | Product detail page                        |
| `/reviews`          | `reviews.tsx`          | All customer reviews                       |
| `/contact`          | `contact.tsx`          | Showroom and WhatsApp contact              |
| `/admin`            | `admin.index.tsx`      | Showroom products catalogue admin          |
| `/admin/login`      | `admin.login.tsx`      | Showroom admin login                       |
| `/superadmin`       | `superadmin.index.tsx` | Private WhatsApp leads & R2 control center |
| `/superadmin/login` | `superadmin.login.tsx` | Private owner/developer login              |

`routeTree.gen.ts` is generated by the router plugin. Do not edit it by hand.
